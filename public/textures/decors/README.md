# Manufacturer decor scans

Downloaded 2026-10-22 from the official manufacturer decor pages for material visualization.
These are manufacturer decor reproductions; the respective manufacturers retain the image rights. Physical samples are the
reference for purchasing/color matching. The Egger images are 1024×576 full-board scans, approximately 2311×1300mm, with woodgrain along the image's horizontal axis.
Swiss Krono's 678×370 store sample has vertical grain; its 60cm preview tile width is an estimate. The full 1300×630mm rapport listed in the main product page could not be downloaded (the manufacturer asset server returns HTTP 503). Sample boundaries use mirrored wrapping to avoid rectangular seams without stretching the image.
